# Debian i386 packages that make up the glibc + GTK3 runtime for the prebuilt
# Firefox 115 ESR tree (see fetch-runtime.sh).  One entry per line; when a
# package was renamed between suites list the alternatives separated by '|'
# (the first name present in the chosen suite's index wins).  Comments and
# blank lines are ignored.
#
# The list is deliberately a little over-inclusive: fetch-runtime.sh copies
# only the shared objects that are reachable through DT_NEEDED from Firefox
# (plus the gdk-pixbuf loaders and the GL stubs), so a package that is
# listed here but not needed costs a download, not disk space in the image.
