Welcome to Links on MaeroOS

You are browsing the real web with Links 2.30, a genuine Linux browser running natively on MaeroOS.

Quick start

  • Press g to type an address (e.g. example.com)
  • Click links with the mouse, scroll with the wheel
  • Press Esc for the menu, q to quit back to the desktop
  • Stuck? Ctrl+Alt+Q force-quits any fullscreen app

Try these

  • example.com — the classic test page
  • info.cern.ch — the first website ever
  • neverssl.com — always plain HTTP
  • your Mac's app repo (needs make repo-serve on the host)

Good to know

  • Inside MaeroOS, your host computer is 10.0.2.2 — typing "localhost" here refers to MaeroOS itself, not your Mac.
  • Only http:// works (this build has no SSL); many modern sites force https and won't load.
